نشت DNS را درست بررسی کنیم

دیدن نام یک کشور یا یک سرویس DNS، به‌تنهایی پاسخ همه سؤال‌های امنیت اتصال نیست.

به‌روزرسانی: ۲۲ آبان ۱۴۰۵

DNS چه کاری انجام می‌دهد؟

DNS نام دامنه را به آدرس IP تبدیل می‌کند. DNS معمولی می‌تواند بدون رمزنگاری ارسال شود؛ روش‌هایی مانند DNS over HTTPS و DNS over TLS برای رمزنگاری این درخواست‌ها به کار می‌روند.

تست را چگونه انجام دهیم؟

  1. نام اینترنت، برنامه اتصال و سرور انتخابی را یادداشت کنید.
  2. با VPN خاموش، نتیجه تست DNS و IP عمومی را ثبت کنید.
  3. VPN را وصل کنید و همان تست‌ها را دوباره انجام دهید.
  4. نتایج را با مسیر مورد انتظار و تنظیمات DNS برنامه مقایسه کنید. اگر DNS ارائه‌دهنده اینترنت برخلاف انتظار همچنان دیده می‌شود، تنظیمات نیاز به بررسی دارد.
تست DNS فقط بخشی از بررسی است. نتیجه آن، وضعیت IPv6، WebRTC یا عبور ترافیک تمام برنامه‌ها از تونل را ثابت نمی‌کند.

چطور نتیجه را تفسیر کنیم؟

پرچم کشور بر پایه مکان‌یابی IP نمایش داده می‌شود و همیشه دقیق نیست. همچنین دیدن Cloudflare یا Google به‌تنهایی ثابت نمی‌کند درخواست از تونل عبور کرده است. مسیر خروجی، DNS مرورگر و تنظیمات برنامه اتصال باید با هم بررسی شوند.

برای پشتیبانی چه بفرستیم؟

تصویر نتیجه قبل و بعد، نام برنامه و نوع اینترنت مفید است. پیش از ارسال عمومی، IP شخصی و اطلاعات اشتراک را بپوشانید.
