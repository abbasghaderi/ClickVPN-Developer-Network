چرا ابزار هوش مصنوعی باز نمی‌شود؟

خطای 403 یا محدودیت منطقه‌ای همیشه یک علت ندارد. مسئله را مرحله‌به‌مرحله بررسی کنید.

به‌روزرسانی: ۲۲ آبان ۱۴۰۵

۱. خود خطا را ثبت کنید

نام ابزار، آدرس صفحه، متن خطا و زمان آن را یادداشت کنید. باز نشدن وب‌سایت، خطای ورود به حساب و خطای API سه مسئله متفاوت هستند.

۲. شرایط ارائه‌دهنده را بررسی کنید

Google AI Studio و Gemini API فهرست مناطق پشتیبانی‌شده و شرایط دسترسی دارند. OpenAI نیز کشورهای پشتیبانی‌شده API را مشخص می‌کند. اتصال شبکه به‌تنهایی شرایط حساب یا مجوز استفاده از یک محصول را تغییر نمی‌دهد.

۳. مسیر اتصال را بررسی کنید

مطمئن شوید برنامه یا مرورگر موردنظر از مسیر انتخاب‌شده استفاده می‌کند. نتیجه مرورگر الزاماً وضعیت ترمینال، Docker یا یک برنامه دیگر را نشان نمی‌دهد. در صورت اختلاف، تنظیمات همان برنامه را با پشتیبانی بررسی کنید.

۴. محدودیت حساب و سهمیه را جدا کنید

در استفاده از API، متن پاسخ، اعتبار حساب، مجوز مدل و سهمیه نیز اهمیت دارند. کلید API را برای عیب‌یابی در صفحات عمومی قرار ندهید.

سرویس دسترسی شبکه، شامل اشتراک پولی ابزارها یا اعتبار API نیست و دسترسی دائمی یا مصونیت حساب از محدودیت را تضمین نمی‌کند.
