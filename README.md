# Click Developer

وبسایت فارسی کلیک دولوپر؛ معرفی Click Pro و Click Plus، خدمات تیمی و آکادمی کلیک.

[مشاهده وبسایت](https://abbasghaderi.github.io/ClickVPN-Developer-Network/)

## ساختار

- `index.html`: معرفی و مقایسه سرویس‌ها، تیم‌ها و پرسش‌های متداول
- `guides.html`: فهرست آموزش‌ها با فیلتر موضوعی
- `getting-started.html`: راهنمای شروع
- `dns-leak-guide.html`: راهنمای بررسی DNS
- `ai-and-dev-access.html`: راهنمای خطاهای دسترسی ابزارها
- `privacy.html`: حریم خصوصی و شرایط استفاده
- `assets/`: استایل، اسکریپت، لوگو و فونت‌های محلی

## انتشار

سایت HTML/CSS/JS است و به نصب وابستگی نیاز ندارد. GitHub Pages از ریشه شاخه main منتشر می‌کند. فایل `.nojekyll` پردازش Jekyll را غیرفعال می‌کند؛ صفحات HTML نهایی هستند.

## نگهداری محتوا

قیمت و وضعیت زنده در سایت ثبت نمی‌شود؛ ادمین مرجع مشخصات بسته‌ها است. Click Pro تست رایگان ندارد. تعداد سرورها و تضمین دسترسی بدون شاهد تازه درج نشود. لینک‌های رسمی فعلی: https://t.me/ClickVpnDeveloper و https://t.me/panelClickVpn.
