### 🛠 سرویس‌ها و پلتفرم‌های پشتیبانی‌شده با مسیریابی اختصاصی (Clean IP)

زیرساخت شبکه ما به گونه‌ای بهینه‌سازی و مسیریابی (Routing) شده است که بدون افت سرعت، قطعی یا خطاهای تحریم (`403 Forbidden`)، به سرویس‌های زیر متصل شوید:

| دسته‌بندی | سرویس‌ها و پلتفرم‌های پشتیبانی‌شده |
| :--- | :--- |
| **توسعه و کدنویسی** | `GitHub` • `GitLab` • `Docker Hub` • `Vercel` • `Stack Overflow` • `Figma` |
| **هوش مصنوعی (AI)** | `OpenAI (ChatGPT)` • `Google Gemini` • `Google AI Studio` • `Cursor` • `AI Mode Chrome` |
| **زیرساخت و کلود** | `AWS (Amazon Web Services)` • `Google Cloud (GCP)` • `Microsoft Azure` |
| **شبکه‌های اجتماعی** | `LinkedIn` • `X (Twitter)` • `YouTube` • `Telegram` • `Instagram` • `SoundCloud` |

---

### 🔐 مسیریابی اختصاصی (Custom Routing) برای پلتفرم‌های خاص

اگر برای کار با یک وب‌سایت، ریپازیتوری، صرافی یا API خاصی با مشکل عدم دسترسی یا محدودیت IP مواجه هستید، کافیست آدرس دامنه آن را برای تیم فنی ما ارسال کنید تا در کوتاه‌ترین زمان، مسیر دسترسی آن در شبکه اختصاصی شما فعال شود.
